Memory architecture

Obsidian is the brain

I use Obsidian as the agent's memory store. Not a black-box embedding blob — a human-readable workspace where facts keep their source, related decisions find each other, and stale knowledge gets edited or killed.

Inspectable

Open the note and see why the agent "knows" something. No mystery weights.

Source-grounded

Facts keep a dossier and a link, not a vibe. Evidence stays attached.

Backlinks

Related decisions find each other automatically. Memory has structure.

File bus

Agents do not share chats. They share notes. Memory survives a thread.

No black box

Stale facts get edited or killed. Nothing is hoarded into one opaque blob.

Portable

Markdown, not a vendor memory product. You own the knowledge base.

Methods

Reliable outcomes

Compact practices that make the agent trustworthy. Not theory — these are the methods I use in live work.

Plan then work Do not start building from a fuzzy ask. Map the job first.
Scoped memory Stable facts, session noise, and procedures stay in separate lanes.
Skills over prompts Repeatable workflows live as playbooks, not one giant instruction blob.
Tools before claims Read files, run tests, screenshot pages. Verify, then speak.
Proof loop Run it. Screenshot. Test. Patch. Then deliver. Never skip evidence.
Fail safe Retry, narrow, ask, or hand off. Never fluent guess when evidence broke.
Isolated subagents Research and QA run in separate contexts so the main thread stays clean.
