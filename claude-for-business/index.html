THE FRAMEWORK

Your New Prompting Framework

01
Role
Who should Claude be? A marketing manager? A bookkeeper? Set the persona.
02
Goal
What finished result do you want? A report? An email? A spreadsheet? Be specific.
03
Context
What does it need to know? Upload files, reference Projects, give examples.
04
Constraints
Tone, structure, length, what to avoid. Set boundaries for better output.
05
Verification
Ask it to check its work or show a plan first. Catch errors before they matter.

RESPONSIBLE USE

Use Claude Responsibly

Always verify important outputs. Claude is confident, not infallible. Check numbers, names, and facts.
Use Team plan controls wisely. Set connectors, permissions, and data boundaries appropriate to your business.
Start small and document wins. One successful task builds confidence better than ten attempted experiments.
Build shared Projects with templates. Consistent context means consistent, reliable output across your team.

Sensitive data? Keep it in Projects, not in open chat. Review Claude's work like you would a new employee's.
